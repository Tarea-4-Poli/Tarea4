
1. Descripción del proyecto

Este proyecto consiste en una aplicación desarrollada en JavaScript que permite representar productos, gestionar un carrito de compra y registrar la finalización de una compra por parte de un usuario.

El objetivo del trabajo es documentar el código y colaborar mediante Git y GitHub, utilizando ramas y pull requests para integrar los cambios de cada integrante del equipo.

2. Objetivos

Documentar las clases, variables y métodos del código JavaScript.

Aprender a trabajar de forma colaborativa con Git y GitHub.

Utilizar un repositorio compartido.

Realizar cambios mediante ramas y pull requests.

Revisar el código y resolver posibles conflictos.

Crear una wiki con información sobre el funcionamiento del programa.

3. Estructura del proyecto

archivo.js: contiene las clases y el ejemplo de ejecución.

README.md: explica el objetivo y la estructura del proyecto.

Wiki de GitHub: contiene información ampliada sobre las clases y el funcionamiento del programa.

4. Descripción de las clases

Clase Producto

Representa un producto mediante tres propiedades: nombre, precio y cantidad.

Su método calcularTotal() multiplica el precio por la cantidad para obtener el importe total del producto.

5. Funcionamiento del programa

El programa crea dos productos: un portátil con precio de 1200 € y cantidad 1, y un ratón con precio de 20 € y cantidad 2.

A continuación, crea un usuario llamado Juan, añade ambos productos a su carrito y finaliza la compra.

El importe total es de 1240 €. El resultado se muestra en la consola y el carrito queda vacío.

6. Trabajo colaborativo

El equipo está formado por tres integrantes. Cada uno documenta una clase diferente: Producto, Carrito o Usuario.

Los cambios se realizan en ramas independientes y se proponen mediante pull requests hacia la rama principal master. Antes de integrar los cambios, se revisa el código y se resuelven los posibles conflictos.
